# שאלונים קליניים

כלי אונליין למטפלת: שליחת שאלוני דיווח עצמי למטופלים בקישור, ציינון ופירוש אוטומטי, ניתוח משולב, תיעוד פגישות וטיוטת דו"ח תפקודי.

- `dist/` – האתר הסטטי שעולה ל-Vercel (`index.html` ממשק מטפלת, `f.html?t=…` מילוי מטופל).
- `js/q1.js`, `js/q2.js`, `js/q3.js` – הגדרות השאלונים: פריטים, סולמות, ציינון, נקודות חתך.
- `js/analysis.js` – הצלבה בין שאלונים, שינוי לאורך זמן, אינדיקטורים תפקודיים, טקסט לדו"ח.
- מסד נתונים: Supabase (`clinical-questionnaires`, eu-central-1) עם RLS; מטופלים ניגשים רק דרך פונקציות token.

בנייה: `npm i && bash build.sh`
